# Privacy Policy — QBitTorrent HomeConnect

**Last updated: 4 September 2026**

QBitTorrent HomeConnect is an independent third-party Chromium browser extension for managing a user's qBittorrent installation through the qBittorrent WebAPI.

## Information the extension stores

QBitTorrent HomeConnect stores the following information locally in the browser using Chrome's extension storage:

- qBittorrent WebUI host/address
- qBittorrent WebAPI key
- HTTP/HTTPS connection preference
- Refresh interval
- Automatic-start preference for newly added torrents
- Light/dark theme preference
- Torrent table column widths

This information is stored locally in the user's browser and is not sent to the developer or to an external analytics service.

## qBittorrent WebAPI communication

The extension communicates directly with the qBittorrent WebAPI endpoint configured by the user.

The WebAPI key is used to authenticate requests to the user's own qBittorrent server. The extension does not collect or transmit the key to the developer.

The extension may send requests to the configured qBittorrent server to:

- Retrieve torrent information
- Monitor torrent status and progress
- Start, stop, force-start, and force-recheck torrents
- Remove torrents
- Add torrent URLs or magnet links
- Access the configured qBittorrent WebUI

## Data collection and sharing

QBitTorrent HomeConnect does not:

- Collect personal information for the developer
- Sell user data
- Share user data with third parties
- Use advertising networks
- Use analytics or tracking services
- Send telemetry to the developer
- Operate a remote data collection server

The extension's network communication is used for its core functionality: communicating with the qBittorrent server configured by the user.

## Remote code

The extension does not download or execute remotely hosted JavaScript or other executable code. All executable extension code is packaged with the extension.

## Changes to this policy

This privacy policy may be updated if the extension's functionality or data practices change. The latest version will be published with the project.
